JDC COUNTINGS Backup

JDC COUNTINGS Backup is an owner-operated utility designed to create encrypted recovery copies of the JDC COUNTINGS database and store them in the owner's designated Google Drive account using rclone.

Access is intended only for the authorized system owner. This public information site does not provide a login, database access, backup downloads, or public access to Google Drive files. The production backup workflow is being prepared and is not yet active.

How the utility works

  • Exports database recovery files from the authorized system.
  • Encrypts the archive using the owner's public recovery certificate before upload.
  • Uses Google's drive.file permission to create and verify designated backup files, rather than requesting access to all files in Drive.
  • Recovery requires the owner's separately held private key.

Privacy and support

Read the Privacy Policy and Terms of Service before authorizing Google Drive access. For support, use the developer support email displayed on the Google OAuth consent screen or contact the JDC Onlinecenter maintainer.
